## Descripción
Aplicación web desarrollada en Django para la reservación de salas de estudio. Incluye un sistema completo de autenticación, validación de reglas de negocio (traslapes, capacidades, horarios) y cancelación de reservaciones con trazabilidad, todo construido bajo la metodología TDD y validado con BDD (Behave + Selenium).

## Requisitos Previos
- Docker y Docker Compose instalados.
- Python 3.11 (opcional, para ejecución local).
- Apache JMeter (para pruebas de rendimiento).
